# Temakuri — Frontend

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

App sobe em http://localhost:5173

## Variáveis de ambiente

| Var | Valor padrão | Descrição |
|-----|-------------|-----------|
| VITE_API_URL | http://localhost:3001/api/v1 | URL da API REST |
| VITE_WS_URL | ws://localhost:3001/ws | URL do WebSocket |
